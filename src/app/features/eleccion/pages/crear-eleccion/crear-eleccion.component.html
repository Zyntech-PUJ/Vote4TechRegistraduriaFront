¿Cómo funciona?

  1. 1
    Nombre descriptivo

    Asigne un nombre claro para identificar la jornada electoral en el sistema.

  2. 2
    Seleccione el tipo

    Escoja el tipo de elección (congreso, presidencia, alcaldes, etc.).

  3. 3
    Configure fechas y modalidades

    Establezca el período electoral y las modalidades de votación disponibles.

  4. 4
    Crear elección

    El sistema validará los datos automáticamente y la elección quedará lista para usar.
